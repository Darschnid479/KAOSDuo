# KAOSDUO: NEON HIGHWAY v5.0 — Norsk spillguide

## Etter hver kampbølge

Du tjener mynter på å skyte fiender. Når bølgen er ferdig, spør spillet om du vil kjøpe våpen. Velg **JA** for å handle, eller **NEI** for å dra direkte videre. Dette gjelder alle bølger unntatt siste seier.

## 50 % Neon Highway — bilbane

Halvparten av portalreisene (tilfeldig 50 % på hver overgang) kan bli en ny kjørebane med perspektivgrafikk. Du styrer én bil på tre kjørefelt. Målet er å nå slutten uten å kjøre inn i biler, lasere eller sperringer.

- **A/D** eller **←/→** bytter kjørefelt ett hakk til siden.
- **Hold Space eller Shift** for nitro (høyere hastighet). Slipp for å lade opp.
- På mobil brukes de tre store **VENSTRE – NITRO – HØYRE**-knappene.
- Plukk opp **veimynter** i ditt kjørefelt. Nære forbikjøringer gir bonusmynter.
- Du mister **aldri HP** ved bilkrasj; du mister én tilgjengelig spesialevne og får prøve den samme bilreisen på nytt.

## 50 % Geometry Run — rytmeportal

Den andre halvparten blir avansert neon-portal med kuber, flyging, tyngdekraft og bevegelige fargelag. Dette er en original bane med lignende arkadefølelse, ikke et Geometry Dash-kart.

- **Kube:** trykk Space / W / opp / ACTION for å hoppe.
- **Flyskip:** hold inne for å fly opp; slipp for å synke.
- **Tyngdekraft:** ett trykk snur gravitasjonen.
- **25 % miniboss i geometridelen:** skytefasen kan starte plutselig midt i banen. Bruk F / X / SKYT, unngå skudd og beseir bossen før du fortsetter på samme sted.
- Ingen HP-tap ved portalfeil, men ett mulig permanent evnetap per mislykkede forsøk.

## Musikk — fikset!

Når du velger **🎸 METAL**, spiller spillet nå en original, tydelig metal-instrumental med riff, bass og trommer. **❄ BLÅ** har original, rolig og koselig musikk. Klikk **🎧 HØR VALGT MUSIKK** på hovedmenyen for å teste. **🎵 MUSIKK PÅ/AV** styrer musikk, mens **M** slår av/på all lyd. Skru opp *medievolumet* på Android/PC om du ikke hører noe.

## Save / Load

Trykk **L** eller **💾 LAGRE**. Lagre manuelt eller last inn autolagring. Bilbanen lagrer kjørefelt, framgang og nitro; portalen lagrer kube-/fly-modus og miniboss-status. Eldre v4.1/v4.2-spilllagringer støttes. For å flytte lagringen mellom enheter bruker du **Eksporter/Importer JSON**.
