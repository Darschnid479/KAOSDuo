# Changelog

## [2.1.0] — 2026-10-29 · PORTAL RUN

### Added
- Nine neon one-button auto-running cube levels, placed after each of waves 1–9.
- Spikes, double spikes, blocks, spinning saws, glowing finish gates, progressive speed, deterministic course generation and original synth rhythm cues.
- New portal jump controls (Space/W/Up/touch) and mobile jump button.
- Portal failure screen showing lost ability, current remaining skills, completion percentage and retry.
- Persistent single-run special ability inventory and ability-loss effects in subsequent arena fights.
- Portal Run HUD, skill indicators and progress, difficulty-scaled tracks, separate animated backgrounds.

### Gameplay rules
- Missing a portal jump never reduces HP or removes XP, level, score or wave progress.
- Every failure removes one random remaining ability: dash, double jump, super, or OVERDRIVE.
- When no skills remain, portal retries continue without further skill loss.
- Finish the portal to start the next arena wave; the final 10th wave ends normally.
- All routes can be finished with one standard jump; losses do not make the cube course impossible.

### Retained
- Single-player only, choose Blue or Metal, four difficulties, 10 combat waves, 3 bosses, 17 upgrades, offline HTML.
