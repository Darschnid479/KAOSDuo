# Contributing to KAOSDUO

Thank you for helping improve the project!

## Report a problem

Open a GitHub issue and include: the platform/browser, what you expected, what happened, and reproducible steps. Screenshots and console error messages are welcome. For Android startup crashes, include the device model, Android version, and a `logcat` excerpt if possible. Do not include personal information, passwords, or private app data.

## Suggest an improvement

Open an issue with a short description of the feature, why it would help, and how it might work in the solo game.

## Code changes

Please keep the game **single-player only**: one selected character on screen and no AI companion. For changes, open a pull request with a clear summary and testing notes. Prefer simple, dependency-free HTML, CSS, and JavaScript where possible.

## Testing checklist

- Start the browser game with Blue and Metal separately.
- Test all four difficulty settings.
- Confirm pause, resume, replay, waves, upgrades and the boss work.
- Check keyboard and on-screen controls.
- Verify responsive layout on mobile and desktop.
- Do not claim an Android build is stable until it passes a device or emulator launch test.
