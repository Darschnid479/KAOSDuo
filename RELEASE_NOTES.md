# 🏎️ KAOSDUO: NEON HIGHWAY v5.0.0

A major update to the free solo pixel-art combat game.

### NEW: 50/50 travel choice

Every trip between battle waves independently selects either **Neon Highway** (50%) or **Geometry Run** (50%). Neon Highway is a stylized pseudo-3D driving stage where you dodge obstacles in three lanes, hold nitro to speed up, grab road coins and earn near-miss bonuses. Geometry Run keeps cube jumps, ship flight, gravity flips and a conditional **25% chance** of a hidden, mid-course shooting miniboss.

### FIXED: metal soundtrack actually plays

Metal now has an **original heavy instrumental MP3**, synthesized and rendered locally, with punchy drums, bass and crunchy guitar-like riffs. Blue gets a separate original, calm, cozy instrumental MP3. Both files are included offline and start on user interaction; a **Preview Music** button makes it easy to check audio before playing. Web Audio synth fallback remains available.

### Returning features

10 waves, 3 bosses, solo character select, 4 difficulties, 8 weapon choices in the coin Armory, an automatic between-wave shop prompt, save/load with JSON export/import, and no HP loss during failed portal/road travel (each failure removes one available special ability).

**Compatibility:** This release is designed for modern desktop and mobile browsers. It is **not a new Android APK**. Previous v4.1/v4.2 local save slots remain readable. Existing GitHub Pages configuration still needs to be enabled by the repository owner.

**Photosensitivity notice:** The game contains rapid neon flashes, bright colors and moving patterns. The portal/highway graphics are original and are not associated with Geometry Dash.
