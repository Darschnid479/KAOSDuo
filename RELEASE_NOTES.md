# 💠 KAOSDUO: PORTAL RUN v2.1.0

**Beat a wave. Become a cube. Survive the geometry. Lose a special power if you crash — NEVER health.**

### What's new
- **9 Portal Run platforming stages**, one between each pair of the 10 combat waves.
- One-button auto-run cube with jumps, spikes, double spikes, blocks, sawblades, rhythm-synced synth effects and animated neon backgrounds.
- **Risk/reward mechanic:** hitting a hazard costs one random remaining special ability (Turbo Dash, Double Jump, Super Attack, or OVERDRIVE), but no HP. Every retry is unlimited.
- Fail screen lists the exact penalty and current abilities; successes return you directly to the next battle.
- Independent Portal Run controls on desktop and touch devices.
- All previous OVERDRIVE features remain intact: 2 selectable heroes, solo only, 4 difficulties, 10 arena waves, 3 boss fights and 17 upgrades.
